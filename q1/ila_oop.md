# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
Encapsulation can help with clumping up variables to create objects in code. The objects can be assigned into being the quantity, name, and price of each item in the
sari-sari store. Applying this OOP can help with organization of variables to help visibility and variable clarity.

### 2. Abstraction
Abstraction can become helpful if you have trouble with memorizing or identifying a big amount of variables, just like the sari-sari store. We can create a big, singular model that can handle
and do a big function, which can be enhanced to be more effective and readable. By creating a big, singular model, many unnecessary data can be removed and be replaced with less and 
important data that the model uses. The sari-sari store can use this OOP to create a compact, singular inventory system model that doesn't need a lot of variables for quantity, name, and price of the items.

### 3. Inheritance
Inheritance is a great addition when creating an inventory system, as it creates a hybrid environment where new files can receive the data of a parent variable, and that parent variable can be removed off the system.
For example, variables that contain the data of the items price can be inherited by a newer variable, and the parent variable can be removed after.
Organization can be improved by being able to delete old files without the worry of erasing important data. 

### 4. Polymorphism
Polymorphism allows the ability of an object to transform into another object that does a different function entirely. This can be useful for an inventory system, like the sari-sari store's,
to reuse an object to create for another purpose, like turning the object of the quantity of the item into the object of the price of the item. This OOP can be useful when the inventory system is being used in real time,
where reusing code is a must when updating on the quickest time possible.

## Reflection
Among the four pillars of Object-Oriented Programming, Inheritance is the most important for the sari-sari store's inventory system. As a store, the stock of the items reduce over time, items get removed from stock and replaced
with a newer one, and the price of items change due to inflation. By using inheritance, we reduce the require manpower to constantly change the variables inside the objects by passing on the required information to a newer batch
of variables. It also increases the longevity of the system as the errors with constant data editing using inheritance is less compared to using only man.
